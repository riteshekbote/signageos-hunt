| Q2 | Reachable? | YES — unauthenticated, any Origin header |
| Q3 | Real impact? | YES — 17-18 static ACAO values including `http://box.signageos.io` (plaintext downgrade) + `https://*.zdusercontent.com` (wildcard); any JS on listed origins can read box HTML cross-origin |

| Q5 | Novel? | YES — first reported in this program |
| Q6 | Not rejected? | YES — static whitelist (not reflected), no credentials flag; not on rejected list |
| Q7 | Reasonable accept? | YES (borderline) — Low severity, no credentials flag limits direct theft, but http:// + wildcard are weak points |

**Verdict: VALID (Low, borderline)**

**Minimal read-only proof:**
```
curl -sI -H 'Origin: https://evil.test' https://box.signageos.io/login/ | grep -i 'access-control-allow-origin' | wc -l  # 17
curl -sI -H 'Origin: https://evil.test' https://box.signageos.io/login/ | grep 'http://box.signageos.io'  # plaintext variant present
```
